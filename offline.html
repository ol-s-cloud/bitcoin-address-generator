Transaction model

The documented model separates an online watch-only machine from an offline signer. PSBT inspection and signing are not implemented in the current Offline Lab.

ONLINE: create unsigned PSBT ↓ QR code or removable media OFFLINE: inspect → verify → sign ↓ signed data ONLINE: broadcast
Never send a private key, WIF or seed phrase through chat, support, analytics, an issue tracker or any networked form.
