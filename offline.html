Offline transaction model

Online watch-only machine creates unsigned PSBT → transfer by QR/removable media → offline machine verifies and signs → return signed data → online machine broadcasts.

Never type a private key, WIF or seed phrase into an AI agent, remote form, analytics product or networked COBRA API.
