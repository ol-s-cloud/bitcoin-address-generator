The CLI provides local randomness, compressed secp256k1 public-key derivation, legacy P2PKH address generation and checksum validation. Testnet is the default network.

Install

Use an isolated Python environment. Until a separately verified package release is published, install from the source repository. 

python -m venv .venv

# macOS / Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate

pip install git+https://github.com/ol-s-cloud/bitcoin-address-generator.git
cobra --version
cobra status

On an air-gapped machine, transfer pre-downloaded and checksummed packages from a connected machine. Do not make an offline signer fetch dependencies from the internet.

Implemented

Commands

cobra status
cobra random --bytes 32
cobra generate
cobra generate --network testnet
cobra derive <64-hex-private-key> --network testnet
cobra validate <address> --network testnet

# Explicit experimental mainnet derivation
cobra generate --network mainnet

generate, derive and validate currently support legacy P2PKH addresses. Always pass the intended network when validating or deriving.

Handle locally

Secret output

Generated private keys are hidden by default. Reveal or save one only in a trusted local environment. 

cobra generate --network testnet --show-secret
cobra generate --network testnet --secret-output ./testnet-key.txt
Exposure paths: shell history, terminal logging, screen recording, cloud-synced folders, backups and clipboard managers can all disclose secrets.
Not implemented

Current limits

The CLI does not construct or sign PSBTs, broadcast transactions, manage HD or seed wallets, orchestrate multisignature policies, or integrate with hardware wallets.

Use testnet or signet for development. Mainnet address derivation is exposed only for explicit experiments and does not make COBRA a production wallet.
