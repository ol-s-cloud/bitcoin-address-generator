THE DESERT / MARS TEST

If you were stranded in a desert — or on another planet — the network would not need to issue you an address.

In principle, a valid secret number plus the Bitcoin derivation rules is enough to reconstruct the corresponding address. But human-made “random” numbers are not secure enough for real funds. COBRA demonstrates the mathematics; secure wallets use cryptographically strong entropy.

Educational use only.COBRA is a cryptography learning tool, not a production wallet. Never fund demonstration addresses or expose a real private key here.

The private key/WIF is the controlling secret. The address is public. Anyone who obtains the private key can potentially spend funds controlled by it.

THE METHOD

Private key → public key → hash → address.

COBRA follows the original repository methodology: begin with a valid 256-bit scalar, derive a secp256k1 public key, apply SHA-256 and RIPEMD-160, prepend the mainnet version byte, calculate the double-SHA-256 checksum, then Base58Check encode the payload.

The browser implementation makes those stages visible. The original Python implementation remains in the repository as a separate implementation of the same core method.

WHERE DOES THE ADDRESS GO?

Nowhere. Until someone pays it.

Generating an address does not register an account with Bitcoin. The address is derived locally. If someone later sends bitcoin to it, that transaction is recorded by the Bitcoin network. Control comes from the corresponding private key — not from an account at COBRA.

1

Keep the secret

The private key — often represented as WIF for import — is what enables spending.

2

Recover with compatible wallet software

A compatible wallet can import or sweep the WIF/private key and locate spendable outputs associated with it.

3

Lose the key, lose control

COBRA stores no recovery copy. A standalone private key has no password-reset authority.
