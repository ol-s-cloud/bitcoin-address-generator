THE METHOD

Private key → public key → hash → address.

COBRA follows the Bitcoin derivation method: valid 256-bit scalar → secp256k1 public key → SHA-256 → RIPEMD-160 → Bitcoin mainnet version byte → double-SHA-256 checksum → Base58Check address.

The browser engine performs the derivation locally in JavaScript so the cryptographic steps can be inspected instead of hidden behind a single output field.

WHERE DOES THE ADDRESS GO?

Nowhere. Until someone pays it.

Generating an address does not register an account with COBRA or Bitcoin. If bitcoin is later sent to it, the transaction/output becomes visible on the Bitcoin network. Control comes from the corresponding private key.

1

Keep the secret

The private key — often represented as WIF for import — enables spending.

2

Recover with compatible wallet software

A compatible wallet can import or sweep the private key/WIF and discover spendable outputs associated with it.

3

Lose the key, lose control

COBRA intentionally stores no recovery copy. There is no COBRA password reset for a standalone Bitcoin private key.

COBRA × AI AGENTS

Machine-speed workflows. Controlled authority.

COBRA’s local randomness and address-derivation primitives can be integrated into AI agents, robots and physical-intelligence systems that allocate receiving addresses or prepare payment workflows in real time. Secret-bearing actions remain behind an explicit wallet, signer or policy boundary.

For high-throughput systems, COBRA supplies the randomness and address layer; an audited signer controls transaction execution.
